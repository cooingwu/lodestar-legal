隐私政策

北辰 Lodestar（以下简称「本应用」）· 发布者 CooHub · 生效日期 2026-11-03 · 版本 v1.0
最终用户许可协议（EULA）→

一、总则：默认零遥测

本应用不收集、不上传、不出售任何用户数据。我们没有账号系统、没有广告、没有分析 SDK、没有崩溃收集服务。应用的一切功能均在你自己的设备上完成。

二、本地处理的数据

以下数据仅在你的设备本地处理与存储，存储目录为 %LOCALAPPDATA%\InfiniteDesk：

  • 桌面与文件信息：为在画布上显示图标，读取文件名、类型、缩略图与修改时间；仅在本地渲染与记忆布局。
  • 照片元数据：相册插件展示拍摄参数（EXIF）时在本地读取，不外发。
  • 位置（可选）：星图「实时星象」功能通过 Windows 系统定位获取经纬度，仅用于本设备上的天文计算，绝不发送到任何服务器。坐标缓存在本地。你随时可以在系统设置中关闭本应用的位置权限，应用会自动回退为按时区估算，功能不中断。
  • 壁纸：读取系统壁纸文件用作画布背景。
  • 应用设置与插件数据：全部保存在上述本地目录。

三、网络活动

本应用仅在以下情形与外部通信，且均由你主动触发或由微软组件执行：

  • 商店授权校验：试用与购买状态由 Microsoft Store 体系验证（Windows.Services.Store），相关数据处理适用微软隐私政策。
  • Microsoft Edge WebView2 运行时：本应用基于该系统组件渲染，其自身行为由微软管辖。
  • 升级跳转：点击「前往商店」时打开微软商店页面。

除此之外，本应用自身不发起任何网络请求。

四、第三方插件

本应用支持第三方插件。插件的权限在安装时明示，其数据行为由插件自身及其隐私政策管辖，不属于本政策范围。

五、删除你的数据

卸载应用后，本地数据目录 %LOCALAPPDATA%\InfiniteDesk 会保留（便于重装恢复）。你可以随时手动删除该目录，即彻底清除本应用的全部数据。

六、未成年人

本应用不面向 13 岁以下儿童，也不故意收集儿童信息。

七、开源与数据致谢

内置星表数据来自 HYG Database（David Nash，CC BY-SA 4.0）与 Yale Bright Star Catalogue 的整理版本。

八、政策变更与联系

政策如有实质变更将在应用内与新版本一同提示。联系我们：cooingwu@foxmail.com。

Privacy Policy (English)

Lodestar ("the app") · Publisher CooHub · Effective 2026-11-03 · v1.0

1. In short: zero telemetry by default

We collect, upload, and sell no user data. There is no account system, no advertising, no analytics SDK, and no crash collection. Everything happens on your device.

2. Data processed locally

  • Files & desktop: file names, types, thumbnails and timestamps are read locally to render icons and remember layout.
  • Photo metadata (EXIF): read locally for the gallery caption; never transmitted.
  • Location (optional): the real-time star chart uses Windows location (latitude/longitude) only for on-device astronomy math. Coordinates never leave your device. You can revoke location permission at any time; the app falls back to a time-zone estimate.
  • Wallpaper: the system wallpaper file is read to paint the canvas background.
  • Settings & plugin data: stored under %LOCALAPPDATA%\InfiniteDesk.

3. Network activity

  • Store licensing: trial/purchase state is verified through Microsoft Store (covered by Microsoft's privacy policy).
  • Microsoft Edge WebView2 Runtime: a Microsoft system component used for rendering.
  • Upgrade link: opens the Microsoft Store product page when you tap "Upgrade".

4. Third-party plugins

Plugins declare their permissions at install time and are governed by their own privacy policies.

5. Deleting your data

Uninstalling keeps %LOCALAPPDATA%\InfiniteDesk (so reinstalls restore your canvas). Delete that folder to erase everything.

6. Children

The app is not directed at children under 13.

7. Credits

Star data derived from the HYG Database (David Nash, CC BY-SA 4.0) and the Yale Bright Star Catalogue.

8. Changes & contact

Material changes ship with an in-app notice. Contact: cooingwu@foxmail.com.
